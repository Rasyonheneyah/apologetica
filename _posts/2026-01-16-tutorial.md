# Guia Completo para Criar um Post

Este documento é **um tutorial completo para qualquer pessoa criar um post no site Apologética Protestante**.  
Ele cobre todos os tipos de Markdown que você pode usar, front matter, imagens, links, citações personalizadas e boas práticas.

---

## 1️⃣ Estrutura do Front Matter

O Front Matter deve ficar **no topo do arquivo** e é obrigatório.  
Exemplo:

```yaml
---
layout: post
title: "Título do Post"
description: "Breve descrição sobre o conteúdo do post"
image: /imgs/posts/exemplo.jpg
date: 2026-01-16
author: Nome do Autor
categories: [refutacoes, anticatolicismo]
tags: [tag1, tag2, tag3]
permalink: /artigos/titulo-do-post/
---
```
**Explicação:**

* `layout` → sempre `post`
* `title` → título do post
* `description` → resumo usado para SEO
* `image` → imagem destacada do post (relativa à raiz do site)
* `date` → data do post
* `author` → autor
* `categories` → categorias do post, você pode colocar mais de um separado por vírgulas. Atente-se pois as categorias serão utilizadas para mostrar os artigos no site.
* `tags` → palavras-chave
* `permalink` → URL final do post

> 💡 Dica: Mantenha o permalink consistente com o título do post.

## 2️⃣ Títulos

Use Markdown padrão:

```markdown
# Título Principal
## Subtítulo
### Mini-subtítulo
```

* `#` → `<h1>` Título Principal
* `##` → `<h2>`  Subtítulo
* `###` → `<h3>` Mini-subtítulo

> ⚠️ Observação: Seu JS atual **não altera `###`**, então eles funcionam normalmente como subtítulos.

---

## 3️⃣ Parágrafos

Escreva normalmente:

```markdown
Este é um parágrafo normal.
Ele suporta **negrito**, *itálico* e [links](https://rasyon.site).
Negrito - **
Itálico - *
Links - [nome do link](link.com)
```

💡 Dica: Separe cada parágrafo com **uma linha em branco**.

---

## 4️⃣ Listas

**Não ordenadas:**

Você usa o traço **-** no começo do texto.

```markdown
- Item 1
- Item 2
  - Subitem 2a
  - Subitem 2b
- Item 3
```

**Ordenadas:**

Você coloca o número do item e um ponto final após ele ( **2.** ). 

```markdown
1. Primeiro item
2. Segundo item
   1. Subitem
3. Terceiro item
```

💡 As listas aplicam identação automática e o CSS já dá espaçamento correto.

---

## 5️⃣ Citações Especiais (`-` e `-#`)

O site aplica estilos especiais para estas citações via JavaScript:


Como usar no Markdown:

```markdown
- Esta é uma citação ( receberá a classe `citacao`, use **-** )  
-# Esta é uma referência (receberá a classe `referencia`, use **-#** )
```

+ * `+` → cria citação com estilo laranja/fundo escuro
-# * `-#` → cria referência com estilo verde/fundo escuro

---

## 6️⃣ Blockquotes

```markdown
> Esta é uma citação em blockquote.
> Pode ter várias linhas.
```

> Blockquote 

O CSS do site aplica cor, espaçamento e itálico.

---

## 7️⃣ Imagens

Para colocar uma imagem:

```markdown
![Texto alternativo](/artigos/imgs/artecruzdecristo.jpg)
```


![Texto alternativo](/artigos/imgs/artecruzdecristo.jpg)


* `Texto alternativo` → usado caso a imagem não carregue
* Caminho → relativo à raiz do site
* Evite links externos, prefira imagens no servidor do site

---

## 8️⃣ Links

```markdown
[Nome do Link](https://rasyon.site)
```

* Pode ser interno ou externo
* CSS aplica cor e hover automaticamente

---

## 9️⃣ Boas Práticas

* Sempre preencha **title, description, date** no Front Matter
* Use imagens **relativas à raiz**
* Prefira Markdown puro, evite HTML
* Teste localmente antes de publicar
* Separe parágrafos e listas com linha em branco para melhor leitura
